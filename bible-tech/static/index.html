                1 · Text layer

                Public-domain only: King James Version, the Westminster Leningrad Codex via Open Scriptures MorphHB, Strong's lexicon, and OpenBible.info cross-references. Hebrew is stored as consonants (vowels and cantillation are display only) and final forms are normalised; versification differences ride on MorphHB's VerseMap so the Hebrew sits on the KJV verse id you actually read.

                2 · Nested words

                Consecutive substrings are looked up in the lexicon; single-letter prefixes (ב ה ו כ ל מ ש) are allowed; a depth-first walk then finds every full-cover segmentation up to four parts. Notarikon is a reading tradition — the instrument shows the hits, not a verdict.

                3 · Anagrams & ciphers

                Temurah (Atbash, Albam), anagram twins by consonant signature, and gematria twins by value (mispar hechrachi). The alphabet is also a set of numbers: that is arithmetic, not doctrine.

                4 · Verse graph

                Weighted edges from the Treasury of Scripture Knowledge, ranges expanded into atomic verse-to-verse links. Click a node and it becomes the new centre.

                5 · Letter codes

                Concatenate a consonantal tape with a run-length map back to OSIS ids, then scan skip distances. Treat the output as a curiosity with a visible caveat.

                Build order

                Compile the text → prove one verse end to end → add the lexicon → add the graph → add the codes. In this repository: python3 build_data.py && python3 server.py.
